# LimitOrderBook

This repo contains my work on simulating market microstructure by recreating the dynamics of the Limit Order Book. 

The dynamics of the Limit Order Book process can be separated into two key components:
- A stochastic process governing the incoming *order flow*, and [^1]
- A deterministic *market clearing procedure*, represented as an operator acting of a pair of distributions of buy and
  sell orders. [^2]



[^1]: The order flow process is generated by the **simulation** library.  
[^2]: The market clearing operator models the Limit Order Book generated by the **engine** library.
